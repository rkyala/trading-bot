===============================================================================
PARALLEL SIGNAL CHANNEL - MANUAL CRONTAB SETUP
===============================================================================

The signal channel needs to be added to your crontab to run every 60 seconds.

Due to sandbox restrictions, I cannot directly modify your system crontab.
Please run ONE of these commands in your terminal:

===============================================================================
OPTION 1: Interactive Crontab Edit (Recommended)
===============================================================================

crontab -e

This will open your default editor. Add this line at the end:

* * * * * /Users/ramayalala/trading_bot/venv/bin/python3 /Users/ramayalala/trading_bot/test_async_signal_channel.py >> /Users/ramayalala/trading_bot/signal_channel.log 2>&1

Save and exit (Ctrl+X in nano, :wq in vim).

===============================================================================
OPTION 2: Non-Interactive Add (If Option 1 Doesn't Work)
===============================================================================

Run this command in Terminal:

(crontab -l 2>/dev/null || echo "") | grep -v "test_async_signal_channel" > /tmp/cron_new.txt
echo "* * * * * /Users/ramayalala/trading_bot/venv/bin/python3 /Users/ramayalala/trading_bot/test_async_signal_channel.py >> /Users/ramayalala/trading_bot/signal_channel.log 2>&1" >> /tmp/cron_new.txt
crontab /tmp/cron_new.txt
echo "✅ Cron job added"

===============================================================================

After adding, verify it's in your crontab:

crontab -l | grep test_async_signal_channel
